Projects

  • Statistical Arbitrage in a Niche Market

    Survival-analysis approach to arbitrage in a slow, data-starved, decentralized market. Co-founded, modeled, and deployed with real money.

    • Co-founded with Lucas Logue. Deployed $13,500 of our own capital and traded it live for about 5.7 months, returning roughly 40 percent.
    • Built a hierarchical Bayesian Weibull Accelerated Failure Time model to pick arbitrage opportunities likely to survive an enforced seven-day hold, and a jump-diffusion SDE to forecast prices.
    • Built the batch-fetching data pipeline (about 150 calls at an 8:1 compression ratio against a rate-limited, soon-to-be-deprecated API) and a Cox proportional-hazards benchmark, where the Weibull AFT came out about 20 percent more accurate under the market’s data sparsity.
  • RISC-V Operating System Kernel

    Preemptive multitasking Unix-like kernel for 64-bit RISC-V, built from bare metal in C and assembly, booting under QEMU (ECE 391).

    • Implemented the PLIC interrupt controller, an interrupt-driven NS16550 UART, a Goldfish RTC, and VirtIO block and entropy drivers at the virtqueue level, plus a cooperative threading system with assembly context switching that I later extended into preemption.
    • Owned Sv39 virtual memory, the block cache over VirtIO and in-memory devices, the syscall interface, and the NGFS file operations behind a unified I/O layer.
  • GPU-Accelerated CNN Convolution

    Profiling-driven CUDA optimization of the convolution layers of a small CNN, im2col plus matrix multiply on an NVIDIA A40 (ECE 408).

    • Used a roofline argument to predict, before writing the kernel, that tensor cores would lose on this memory-bound workload, then confirmed it with nsys and Nsight Compute and traced the bottleneck to address arithmetic rather than matmul throughput.
    • Worked through which textbook optimizations (constant memory, FP16, CUDA streams) helped or hurt on this workload and why, learning to read occupancy, memory throughput, and stall reasons as one workflow.
  • Audio Spectrum Visualizer

    FPGA system that streams audio off an SD card and draws it on an HDMI display in real time (ECE 385).

    • Built a continuous SD-to-BRAM streaming engine in SystemVerilog through an 8KB circular buffer with rate-matched throttling, and interrupt-driven 44.1 kHz playback via an AXI timer ISR for distortion-free output.
    • Built five real-time visualization modes on a 60 FPS HDMI text display, integrating a MicroBlaze processor, SPI SD interface, PWM audio output, and USB HID input.
  • Heart Restart: Dual-Shock Defibrillator

    Microcontroller-controlled AED built for two sequential biphasic shocks, with strict galvanic isolation between the high-voltage side and the STM32 (ECE 395).

    • Designed the five-rail power subsystem, converting an 18V battery input to five regulated rails using TPS5420 buck converters and LT1054 charge-pump inverters, validated in LTspice.
    • Designed a 4-layer mixed-signal PCB in KiCad with 200V-plus creepage and clearance, and integrated AMC1200 isolation amplifiers and isolated DC-DC converters to keep the high-voltage pads separated from the STM32 control logic.
